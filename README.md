# aws-cloud-developing-flashcards

One-page AWS Academy practice flashcards, arranged by module: https://sulte4.github.io/aws-cloud-developing-flashcards/

- **Cloud Developing, modules 2-13:** 120 original questions.
- **Cloud Foundations course assessment, F1-F10:** 65 questions from two public Quizlet sets (de-duplicated, typos fixed). Where the two sets disagree, the card says so.
- Multiple-choice and flashcard modes, module quick-picks, saved progress, missed-question review and bookmarks.
- Light / dark theme toggle (top-right). Follows your OS until you pick one; the choice is remembered.
- Single static file: open `index.html` or serve it with GitHub Pages. Progress lives only in your browser (localStorage).
- `source-data/` holds the raw Quizlet exports and the course outline.
