# aws-cloud-developing-flashcards

One-page flashcards for the Cloud Computing course (AWS Academy), arranged by module: https://sulte4.github.io/aws-cloud-developing-flashcards/

Structure follows the Moodle course and syllabus:

- **Midterm quick-pick, Foundations 1-10:** 165 cards. Questions from two public Quizlet course-assessment sets (de-duplicated, typos fixed), plus cards written from the Moodle slides for Foundations modules 1, 5, 6 and 9.
- **Endterm quick-pick, Developing 1-6:** 174 cards written from the Moodle slide decks (Intro, SDKs and CloudShell, S3, IAM, DynamoDB, API Gateway) and the original practice set.
- **Developing 7-13:** 70 original practice cards.
- Where sources disagree, the card says so.
- Multiple-choice and flashcard modes, module quick-picks, saved progress, missed-question review and bookmarks.
- Light / dark theme toggle (top-right). Progress lives only in your browser (localStorage).
- Single static file: open `index.html` or serve it with GitHub Pages.
- `source-data/` holds the raw Quizlet exports and the course outline.

Not yet covered from slides: Foundations modules 2, 3, 4, 7, 8 and 10 (the decks are on Moodle but Chrome blocked the downloads) and Developing modules 7-13 (not on the Moodle course).
