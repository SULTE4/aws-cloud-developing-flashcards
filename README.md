# aws-cloud-developing-flashcards

Practice flashcards for AWS Academy Cloud Developing (Modules 2–13): 120 questions, multiple-choice and flashcard modes, module quick-picks, saved progress, missed-question review and bookmarks.

- Light / dark theme toggle (top-right). Follows your OS until you pick one; the choice is remembered.
- Single static file: open `index.html` or serve it with GitHub Pages.
- Progress lives only in your browser (localStorage).
